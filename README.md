# agent_search
This agent does search for a specific topic in a list of Youtube channels, web sites and locally archived material (obsidian).
Its goal is to produce a list of Top relevant materials to a specific topic.
The following step is to manually select the material to be added to the local knowledge base (obsidian).

The system is composed of the following components:
1. Agent search (python)
2. Local knowledge base (obsidian)
3. List of sources (youtube channels, web sites)
